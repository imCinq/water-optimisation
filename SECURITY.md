# Security Policy

## Scope

Security reports should cover code in this repository and released development builds.

## Report privately

Do not publish credentials, tokens, personal information, private server logs, or exploitable details in a public issue. Use the private repository's approved security-reporting process.

## Project-specific concerns

Please report:

- unintended network requests;
- changes to packets or server-visible state;
- unsafe file writes;
- leaked identifiers in diagnostics;
- bypasses of server rules;
- crashes caused by malformed or unexpected fluid, block, or renderer state.
